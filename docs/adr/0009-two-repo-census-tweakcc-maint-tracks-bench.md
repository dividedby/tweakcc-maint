# 0009 — One census tracks two repos: tweakcc-maint also tracks `dividedby/bench`

Status: Superseded (2026-06-12).

The roadmap/census system this ADR described was decommissioned: GitHub Issues are now
the single source of record for both `dividedby/tweakcc-maint` and `dividedby/bench`, so
the census doc, mirror workflow, and roadmap drift-nudge hooks no longer exist. The
two-repo *tracking* decision still holds — both repos are steered from here (see CLAUDE.md
"Owned sibling" and `docs/agents/issue-tracker.md`); only the census-doc machinery is retired.
